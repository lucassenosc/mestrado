# Execução do projeto

## Passos gerais

1. Clonar o repositório.
2. Criar o ambiente virtual.
3. Instalar as dependências.
4. Baixar os dados pelo Google Drive.
5. Colocar as pastas `data/`, `data2/` e `data3/` na raiz do projeto.
6. Abrir o projeto no VS Code.
7. Selecionar o kernel Python do ambiente `.venv`.
8. Executar os notebooks.
